# Инструкция по иконкам

- Исходное изображение для создания иконки можно делать в размере `1024 x 1024` пикселя, чтобы получить более качественную и аккуратную графику.
- Итоговый файл иконки кладётся в папку кнопки квадратным, размером от `32 x 32` до
  `128 x 128` пикселей. Рабочее значение плагина — `96 x 96`: в ленте Revit иконка
  рисуется 32 x 32, а запас нужен для экранов с масштабом 125–150 %.
- Файл 1024 x 1024 в папке кнопки недопустим: pyRevit разворачивает картинку в память
  целиком, и полсотни таких иконок замедляют запуск Revit.
- Иконки должны быть на прозрачном фоне.
- Формат файла рекомендуется `PNG`.
- Имя файла иконки должно быть `icon.png`.
- Для основной палитры иконок предпочтителен слегка синий оттенок, чтобы новые иконки гармонировали с соседними кнопками на панели.
- Если на иконке нужно визуально отделить важную деталь или действие, допускается локально использовать оттенок зелёного как акцент.
- Изображение должно уверенно заполнять рабочую область иконки, без слишком больших пустых полей.
