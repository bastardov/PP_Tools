# История изменений

Версии помечаются тегами git. Свежая разработка всегда в ветке `main`,
стабильные состояния — в разделе [Releases](https://github.com/bastardov/PP_Tools/releases).

## v1.0 — 2026-09-21

Первая публичная версия. Расширение к этому моменту больше года
используется в реальном проектировании ОВиК.

### Состав

- **Марки** — сопоставление и копирование марок по типу и семейству, марки
  воздуховодов и труб, марки пары труб, вертикальные участки (в том числе
  автоматический отбор стояков), применение типа марки от эталона,
  маркировка по шаблону правил, «Инструменты меток», «Раздвинуть марки».
- **Теплопотери** — нарезка полов и кровли по пространствам, перенос данных
  из пространств, определение и перестановка сторон света, объединение кусков
  стены в одну, заполнение плиты с вырезами под колонны, окраски для визуальной
  проверки, «Проверка теплопотерь» с библиотекой проверок.
- **Расчеты** — длина коридора по помещениям своей модели и из связи,
  расход воздуха из пространств.
- **Проверка** — проверка спецификации, проверка модели, аудит модели,
  коллизии, окраска элементов по значению параметра.
- **Рабочие инструменты** — «Опуск / Подъем трассы» (по отметке, несколько
  участков сразу, перенос присоединённого оборудования), «Соединить под углом»,
  «Выровнять уклон по эталону», передача параметров по MEP-соединениям.
- **Оформление** — имена листов по видам и планам, «Разместить на листы»
  (режимы «Планы» и «Виды», ориентация, заголовки видов), связи в шаблонах
  видов, полутона, 3D-виды перекрытий и коллекторов, разрез из 3D-вида.
- **Служебное** — общие настройки плагина, локальная статистика использования
  кнопок, обмен данными модели через JSON (в том числе с ИИ-агентами).

### Подготовка к публикации

- README с описанием, установкой и составом расширения.
- Лицензия MIT.
- Личные настройки (`lib/pp_settings.json`) выведены из репозитория:
  файл создаётся сам из значений по умолчанию, рядом лежит пример
  `lib/pp_settings.example.json`.

## Изменения до первой версии

Ниже — заметные правки с 24.08.2026, когда история плагина перешла под git.
Более ранние инструменты вошли в первый коммит целиком.

### Сентябрь 2026

- «Разместить на листы»: новая кнопка и `lib/pp_sheet_naming`, фильтр планов
  по шаблону вида, режим «Виды» с несколькими видами на листе, выбор ориентации
  листа, оформление заголовков видов.
- Библиотеки проверок разнесены по файлам: `lib/model_checks/`,
  `lib/spec_checks/`, `lib/heatloss_checks/`.
- «Проверка Модели»: проверки «ДП–ДВ» и «Высота дымоприёмного устройства».
- «Переставить стор. света»: сдвиг готовых сторон света по кругу после
  разворота здания.
- «Заполнить плиту»: вырезы под колонны, чтение контура через профиль эскиза,
  закрытие выреза по прямой.
- «Объединить стены»: новая кнопка и ядро `lib/pp_wall_merge` — объединение
  кусков стены в одну, перенос проёмов, поддержка непрямоугольных кусков
  и витражей, подробная диагностика отказов.
- Окна проверок: клик по подписи строки выбирает строку, а не переключает галочку.

### Август 2026

- Переход на git вместо ручных копий в BACKUPS, служебные `git_*.bat`.
- Все `forms.alert` заменены на собственные окна плагина (`lib/pp_wpf`).
- «Опуск / Подъем трассы»: режим «По отметке», обработка нескольких участков
  за раз, перенос присоединённого оборудования, перепад отдаётся примыкающему
  стояку.
- «Раздвинуть марки»: новая кнопка и ядро `lib/pp_tag_layout` с учётом выносок.
- «Расход из пространства»: скрипт Dynamo переведён в кнопку плагина.
- Своё окно выбора листов с фильтром по разделу проекта (`lib/pp_sheet_picker`).
- «Марки помещений из связи»: существующие марки приводятся к типу «Номер Имя».
