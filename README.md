# PP_Tools — расширение pyRevit для инженеров ОВиК

Набор инструментов Revit, собранный в реальной проектной работе по отоплению,
вентиляции и кондиционированию: расчёт теплопотерь через пространства, марки,
оформление листов и 3D-видов, проверки модели и спецификаций, рабочие
инструменты для трасс.

Расширение написано на IronPython под [pyRevit](https://github.com/pyrevitlabs/pyRevit)
и раскладывается двумя вкладками ленты — **PP_ОВиК** и **PP_ОВиК 2** —
это примерно 60 кнопок в 15 панелях.

## Требования

- Autodesk Revit 2022 (разрабатывалось и проверялось на нём; на соседних
  версиях большинство инструментов должно работать, но это не проверено)
- pyRevit 4.8 или новее
- Windows

## Установка

**Вариант 1 — git (удобно обновлять):**

```cmd
cd %APPDATA%\pyRevit-Master\extensions
git clone https://github.com/<ваш-аккаунт>/PP_Tools.extension.git PP_Tools.extension
```

**Вариант 2 — скачать архивом:** кнопка `Code → Download ZIP`, распаковать в
`%APPDATA%\pyRevit-Master\extensions\` так, чтобы папка называлась именно
`PP_Tools.extension`.

После этого в Revit: `pyRevit → Reload`. На ленте появятся вкладки
**PP_ОВиК** и **PP_ОВиК 2**.

Обновление до свежей версии:

```cmd
cd %APPDATA%\pyRevit-Master\extensions\PP_Tools.extension
git pull
```

и снова `pyRevit → Reload`.

## Настройки и приватность

- Настройки хранятся в `lib/pp_settings.json`. Этого файла нет в репозитории —
  он создаётся сам при первом запуске из значений по умолчанию. Пример
  заполненного файла с рабочей конфигурации лежит рядом:
  `lib/pp_settings.example.json` (можно скопировать и переименовать).
- Расширение ведёт локальный счётчик запусков кнопок в папке `telemetry/`
  и рабочие логи в `_logs/`. Обе папки не попадают в репозиторий, данные
  никуда не отправляются и остаются на вашем компьютере.

## Для ИИ-агентов и разработчиков

Расширение писалось вместе с ИИ-агентами, поэтому правила проекта лежат
прямо в репозитории — агент читает их и работает по ним:

- `AGENTS.md` — общие правила работы с проектом: структура, порядок действий,
  чего нельзя делать (например, переименовывать папки `.tab`/`.panel`/`.pushbutton`).
- `Memory.md` — подробная память по проекту: как устроен каждый инструмент,
  какие решения приняты и почему.
- `UI.md` — правила оформления окон на WPF: готовые компоненты из `lib`,
  палитра, типографика, грабли IronPython.
- `ICONS.md` — требования к иконкам кнопок.
- `bundle.yaml.MD` — как оформлять `title` и `tooltip` кнопок pyRevit.

Общий код вынесен в `lib/` — темы и база окон WPF (`pp_theme.xaml`, `pp_wpf.py`),
списки с галочками, выбор листов и параметров, библиотеки проверок
(`lib/spec_checks/`, `lib/model_checks/`, `lib/heatloss_checks/`).
